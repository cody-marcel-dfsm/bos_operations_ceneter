# BOS plugin logo family

The BOS plugin family uses a square deep-navy field, an electric-blue angular
shield, bold white stacked typography, and one simple workflow-specific symbol.

| Identity | Canonical asset | Package status |
| --- | --- | --- |
| BOS — Business Operating System | `products/bos/assets/bos-logo.png` | Active plugin asset |
| Education Center | `products/education-center/assets/education-center-logo.png` | Active plugin asset |
| Lead Director CRM | `brand/assets/lead-director-crm-logo.png` | Runtime brand asset; no standalone plugin created |
| Marketing Director | `products/video-ads/assets/marketing-director-logo.png` | Source asset for the disabled `video-ads` package |

Shared production palette:

- Deep navy: `#061638`
- Electric blue: `#087BFF`
- White: `#FFFFFF`

The Education Center mark uses an open-book motif. Lead Director CRM uses a
pipeline-to-target motif. Marketing Director uses a play-and-growth motif for
its video advertising skill set.
