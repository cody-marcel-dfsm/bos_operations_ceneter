# Weekly director summary content contract

Render one concise, director-ready operating summary for the full resolved
Monday-through-Sunday period. Follow `bos-visual-output`. Use aggregate counts
and operational conclusions by default; include family-level details only when
they are necessary for a stated follow-up action.

## Header

- Title: `Weekly Director Summary — <Month D–D, YYYY>`
- Location and time zone
- Generated-at time
- Source status: complete or source-specific partial

## Executive snapshot

Lead with up to five evidence-backed findings covering material performance,
changes, wins, risks, and immediate decisions. State unavailable evidence as
unavailable and never convert it to zero.

## Weekly operating scorecard

| Area | Result | Change or context | Required action |
|---|---:|---|---|
| Classes and enrollments | | | |
| Attendance and capacity | | | |
| Leads and response | | | |
| Trials and conversions | | | |
| Parent follow-ups | | | |

Use the entire weekly period for every row. Preserve source provenance and label
metrics that cannot be compared with a prior period.

## Wins

List evidence-backed positive outcomes from the reporting week. Connect each
win to the relevant class, enrollment, lead, trial, family action, or operating
improvement without exposing unnecessary personal data.

## Risks and unresolved actions

List overdue follow-ups, missed or unconfirmed trials, enrollment or capacity
risks, source conflicts, missing evidence, and provider capability blockers.
Assign a clear next action when the evidence supports one.

## Next-week priorities

Return no more than seven prioritized actions for the following local week.
Use action verbs, an owner when BOS returns one, and a due date when the source
supports it. Never invent owners or deadlines.

## Source notes

State the reporting period and each source used. Identify source-specific
partial sections and retrieval timestamps. End with
`Summary scope: content prepared only; no distribution performed.`
