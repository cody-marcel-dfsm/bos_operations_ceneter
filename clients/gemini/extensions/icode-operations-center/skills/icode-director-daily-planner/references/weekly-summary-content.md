# Weekly director summary content contract

Render one concise, director-ready operating summary for the resolved local
Monday-through-Sunday period. Follow `bos-visual-output`. Camps, daily rosters,
family phone contacts, parent follow-ups, and upcoming events are the primary
content. Show the minimum family information needed for authorized school
operations.

## Header

- Title: `Weekly Director Summary — <Month D–D, YYYY>`
- Location and time zone
- Generated-at time
- Source status: complete or source-specific partial

## Camps this week

Place this section first. Create one subsection per camp, ordered by first
scheduled occurrence. Show camp name, date range, daily time, instructor,
capacity, and enrollment count when BOS returns them.

Within each camp, list every expected student on every scheduled day:

| Day/date | Student | Parent/guardian | Primary family phone | Enrollment source | Parent note or action |
|---|---|---|---|---|---|

Use exactly these enrollment-source labels:

- `Paid enrollment` for a source-backed paid Calimatic enrollment;
- `Care.com` for a confirmed Care.com backup-care child-day explicitly assigned
  to this camp occurrence and date;
- `Bright Horizons` for a published BOS record explicitly identifying Bright
  Horizons and assigning the student to this camp occurrence and date; or
- `Needs review` when evidence is missing, conflicting, or cannot establish
  the payer.

Keep confirmed but unassigned Care.com or Bright Horizons child-days out of a
camp roster. List them under Family calls and camp exceptions as `Needs review`
placement demand.

Preserve a student on each day they are scheduled to attend. When a camp or
roster source is unavailable, retain the camp heading and state the missing
capability instead of reporting zero students. Write `Missing in BOS — call
list incomplete` when the family phone is absent.

Parent note or action contains only a source-backed operational fact from a
relevant parent communication, such as confirmed absence, changed attendance
day, pickup issue, schedule question, accommodation requiring preparation, or
a requested callback. Omit message bodies, sensitive narrative, and unrelated
family information.

## Family calls and camp exceptions

List the director's camp-related calls in urgency order:

| Priority | Family/student | Phone | Camp/day | Reason | Source-backed next action |
|---|---|---|---|---|---|

Include missing confirmations, unresolved attendance changes, missing phone
numbers, schedule conflicts, duplicate payer records, and other exceptions
that affect service this week. Never invent a reason, owner, or deadline.

## Upcoming events

Highlight material Calendar events during the resolved week and immediately
following local week:

| Date/time | Event | Operational impact | Preparation or family action |
|---|---|---|---|

Include only events affecting staffing, rooms, supplies, camp schedules,
community commitments, or family communication. State `No upcoming events
returned by Calendar` only after a successful bounded Calendar search.

## Secondary operating snapshot

After the camp sections, summarize other evidence-backed weekly operations:

| Area | Result | Change or context | Required action |
|---|---:|---|---|
| Other classes and enrollments | | | |
| Attendance and capacity | | | |
| Leads and response | | | |
| Trials and conversions | | | |
| Other parent follow-ups | | | |

Keep financial, marketing, transaction, ownership-transfer, and general
business commentary secondary. Include it only when it creates an immediate
director action or the user explicitly requests it.

## Wins, risks, and next actions

List evidence-backed wins and risks connected to this week's camps and service
delivery first. Then return no more than seven prioritized actions. Use action
verbs, an owner when BOS returns one, and a due date when the source supports
it. Never invent owners or deadlines.

## Source notes

State the reporting period and each source used. Identify source-specific
partial sections and retrieval timestamps. End with
`Summary scope: content prepared only; no distribution performed.`
