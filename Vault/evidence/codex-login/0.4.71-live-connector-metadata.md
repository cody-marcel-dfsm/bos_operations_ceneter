replacement ID `asdk_app_6a97966a296c8191a5f9b937e7650be3`.

- Authenticated

  returned HTTP 200.

  `https://dfsm.ai/mcp/apps/bos/platform` and advertised OAuth with PKCE.
- Connector metadata creation used automatic connection disabled. No connector
  link endpoint was called and no BOS OAuth flow was launched.

## Regression boundary

The package, generated `.app.json`, and portable contract must never adopt this
replacement. They derive the permanent established identity from
`products/bos/product.json`. This evidence proves only that the failed repair
created resolvable metadata. Its correlated request/response logs redact
authentication secrets, account identifiers, organization identifiers, and
connector owner identifiers.

This evidence proves native metadata availability. Visual acceptance remains a
