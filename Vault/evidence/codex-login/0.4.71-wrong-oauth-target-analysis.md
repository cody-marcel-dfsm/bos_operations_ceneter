# BOS 0.4.71 Connect target failure

- Date: 2026-09-02
- Scope: Issue #0001, GPT plugin-detail Connect flow
- Screenshot: `0.4.71-wrong-oauth-target.png`
- Screenshot SHA-256:
  `3ebb03d88b9319b668204d3d9b37717767c2b61afdbb97631a6eb157e3e99429`

## Observed result

After a clean manual installation, the BOS plugin presented its native Connect
flow. Invoking Connect opened `auth.openai.com/about-you`, requested ChatGPT
profile information, and failed with `duplicate_email`. The flow never reached
the BOS platform authorization endpoint.

## Correlated read-only evidence

The generated package declares immutable connector
`plugin_asdk_app_6a7cb1cc330c81918aa63d96aeeaba91`. The live Codex diagnostic
then observed:

- `app/read` returned no app and listed raw ID
  `asdk_app_6a7cb1cc330c81918aa63d96aeeaba91` in `missingAppIds`.
- Full `app/list` enumeration scanned 3,373 records and found no matching app.
- The account-owned plugin catalog was empty.
- Authenticated connector GET for that exact raw ID returned HTTP 404
  `Connector not found`.
- The unresolved package declaration received a ChatGPT-hosted install URL
  beginning `https://chatgpt.com/apps/`.

Independent live BOS discovery remained healthy:

- MCP resource: `https://dfsm.ai/mcp/apps/bos/platform`
- Authorization-server issuer: `https://dfsm.ai`
- Authorization endpoint: `https://dfsm.ai/api/v1/mcp/oauth/authorize`

## Causal conclusion

The package does not author `auth.openai.com/about-you`. Its `.app.json`
declares a registered connector ID. The external record for that immutable ID
is absent, so ChatGPT cannot resolve the BOS MCP resource and falls into its own
app/account onboarding path. The repository-native `product:codex sync`
workflow requests restoration through that exact ID and rejects success unless
a same-ID post-read resolves the exact BOS MCP resource. It never invokes
new-product provisioning for BOS.

## Prevention

Keep the immutable connector ID, MCP resource, OAuth issuer, authorization
endpoint, provider endpoint, and account-selection policy in
`products/bos/product.json`. Generate every client metadata artifact and
contract from that file. Post-release acceptance must combine native visual
evidence with a read-only connector lookup that proves the exact immutable ID
resolves to the exact BOS MCP resource URL.
