# Release Review: 0.4.55 Repository Marketplace Restoration

Date: 2026-08-29

## Scope

Review of the corrective release diff restoring Git marketplace entrypoints,
preventing the all-client uninstaller from deleting repository source files,
regenerating all client versions, and correcting Codex installation guidance.

## Root cause

Release 0.4.54 removed `.agents/plugins/marketplace.json` and
`.claude-plugin/marketplace.json` from the repository root. Codex Git marketplace
ingestion requires a supported manifest at the checked-out root. The all-client
uninstaller incorrectly treated those package source files as local installation
artifacts, and tests encoded their deletion as expected behavior.

## Findings

No blocking findings in the corrective diff.

## Evidence

- `.agents/plugins/marketplace.json:1-32` is a valid Codex marketplace root and
  routes BOS and Education Center to their generated package directories.
- `.claude-plugin/marketplace.json` restores the corresponding Claude Git
  marketplace entrypoint.
- `scripts/build-packages.mjs` derives both root entrypoints from the generated
  client catalogs, keeping product order, policy, metadata, and paths aligned.
- `scripts/uninstall-bos-all-clients.mjs:245-397` removes only installed client
  registrations and validated caches; it has no repository source-root deletion
  path.
- `scripts/check-package.mjs` compares each root entrypoint byte-for-byte at the
  JSON object level with the transformed generated client catalog and fails the
  release if either entrypoint is missing or drifts.
- `tests/all-clients-uninstall.test.mjs` verifies both repository manifests
  survive a complete all-client uninstall.
- `tests/package-model.test.mjs` verifies the root catalogs route to the exact
  generated Codex and Claude plugin directories.

## Validation

- Isolated Codex home accepted the repository root as marketplace
  `bos-education-center`.
- The isolated marketplace installed BOS `0.4.55` and Education Center `0.4.55`
  from the restored root paths. The real user Codex home remained unchanged.
- Both Codex plugins passed the system plugin validator.
- `npm run release:check` passed package generation, package/credential checks,
  the single BOS connection contract, and all 183 tests.
- `git diff --check` passed.

APPROVED
