# Release 0.4.78 Issue #0001 authentication and static-catalog review

Date: 2026-09-02

## Scope

Reviewed the complete actual working-tree diff for the Issue #0001 Codex BOS
authentication activation correction and the accepted authenticated discovery
flow. The review included all tracked changes, untracked RCA and Vault manifest
artifacts, canonical Vault architecture and issue history, product ownership,
generated clients, package validators, installer/runtime verification, tests,
repository boundaries, and credential safety.

## Findings

No material findings remain.

The first two review passes identified stale authority-scoped discovery
instructions. The corrected tree now reserves static-catalog refresh for OAuth
connection, package/schema, transport, and session events. Role, plugin,
capability, provider, and license changes refresh context, operation status, or
service inventory and rely on the authoritative `tools/call` result.

## Prevention

authorization. Require every new authority-state workflow to refresh context,
operation status, or service inventory and to treat `tools/call` as the
authorization decision. Preserve the broadened regression scan and generated
